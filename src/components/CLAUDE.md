# src/components — componentes React compartilhados (UI primitiva + features)

Camada de apresentação em React 19 / Next 15 com shadcn/ui (estilo `new-york`, ícones `lucide`, aliases em `components.json`). Não é sensível a segurança por si só, mas consome dados de alunos via hooks; autorização fica no backend.

## Responsibility

Contém primitivos shadcn em `ui/` (`button.tsx`, `dialog.tsx`, `tabs.tsx`...), componentes de feature agrupados por área (`classroom/`, `agendas/`, `assessments/`, `study-group/`, `teaching/`, `layout/`...) e hooks de UI colocalizados (`use-*.ts`). Regra de negócio NÃO fica aqui: mora em `src/domains/*/services` (e schemas/estado puro em `src/domains/*`). Páginas específicas por papel ficam em `src/app/(papel)/**/_components`; aqui entra só o que é reutilizado entre papéis ou entre telas.

## Key patterns

- Primitivos de `ui/` usam `cva` + `cn` de `@/lib/utils` e `React.forwardRef`; `Button` expõe `buttonVariants`, `variant`/`size` e `asChild` (via `Slot`).
- Componentes de feature são `'use client'`, com props tipadas em `interface <Nome>Props` (ex.: `NowInClassStripProps`) e named exports.
- Lógica com estado/efeitos vai para hooks: `useSessionClock` (um único `setTimeout` até a próxima fronteira, com `resetKey`), `useClassEvents` (SSE com fallback de polling, `merge` por `seq`, status `'live' | 'updating' | 'offline'`).
- Funções puras ficam exportadas ao lado do hook/componente para teste direto: `nextBoundaryDelay`, `continueInChatText`.
- Componentes importam tipos e reducers de `@/domains/classroom/class-state` em vez de reimplementar regra.

## Applied rules

Rules active in this directory — read them before touching code here:

- @.claude/rules/react/coding-standards.md — sem `key={index}`, sem estado duplicado, sem lógica de negócio no componente (extrair `use<Nome>`), props `<Nome>Props`, `export default` só em páginas, `aria-label`/texto visível em todo elemento interativo.
- @.claude/rules/next/coding-standards.md — Server Component por padrão; `"use client"` só com interatividade; `next/image` em vez de `<img>`; `useSearchParams` dentro de `<Suspense>`.
- @.claude/rules/04-code-quality.md — nomes que revelam intenção, sem código morto nem console.log, arquivos com responsabilidade única.
- @.claude/rules/05-testing.md — testar só renderização condicional, validação de formulário, hooks com estado e a11y crítica; UI puramente visual não ganha teste; relógio/rede injetados ou falsos.

## Local conventions

- Testes em `<area>/__tests__/*.test.ts(x)`, ambiente jsdom via `// @vitest-environment jsdom`, `renderHook`/`act` de `@testing-library/react` e `vi` fake timers; nomes de teste em português descrevendo comportamento.
- Imports internos sempre pelo alias `@/` (`@/components/ui/button`, `@/domains/...`).
- Novos primitivos shadcn entram em `ui/` pelo CLI (`components.json`, cor base `slate`); cores de marca via classes `brand-teal`/`brand-orange`.
- Hooks: um arquivo por hook, `use-kebab-case.ts`, retorno tipado explicitamente.
